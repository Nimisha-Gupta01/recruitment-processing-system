# Abstract
## Online Recruitment Processing System

**Course:** Full Stack Application Development (FSAD)
**Team:** 2 Members | MTECH – BITS Pilani

---

The Online Recruitment Processing System is a web-based application designed to fully automate the end-to-end recruitment lifecycle within an HR division. The system bridges the gap between employers seeking qualified candidates and job seekers looking for suitable opportunities — eliminating manual, paper-based processes and reducing time-to-hire.

The platform provides two distinct roles: **Employers** and **Candidates**. Employers can register their organizations, post job vacancies with detailed requirements (designation, salary, qualification, employment type), and search the candidate pool using filters such as qualification, location preference, salary expectation, and merit. Candidates can register, build their profiles, specify job and location preferences, browse available vacancies, apply for positions, and track their application status in real time.

The system automates interview scheduling — once an employer identifies a matching candidate, a meeting is scheduled and both parties are notified. Post-interview, the employer updates the outcome (Selected / Offered / Recruited / Rejected), which is reflected in the candidate's dashboard and triggers an automated email notification. Comprehensive reports are available to both employers (recruitment summaries, interview records) and candidates (application history, status reports).

Built on a modern three-tier architecture using **Spring Boot** (REST API backend), **ReactJS** (frontend), and **MySQL** (relational database) with **Spring Data JPA / Hibernate** for ORM, the system is designed for scalability, role-based security, and ease of use.

**Key Modules:**
1. Registration & Login Module (Role-based: Employer / Candidate)
2. Candidate Search & Scan Module
3. Interview Scheduling & Details Module
4. Candidate Job Registration & Preferences Module
5. Job Search Module
6. Reports Module
7. Email Notification Module

**Special Features:**
- Merit-based and preference-based intelligent candidate filtering
- Real-time application status tracking
- Automated email notifications on status changes
- Role-based access control (Employer vs Candidate)
- Interview scheduling with outcome tracking
